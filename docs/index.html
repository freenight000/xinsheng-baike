The Problem

信息都在，但没有人知道该翻哪一份

新生最大的困难不是“没有信息”，而是信息散在几十份培养方案、几百页学生手册和每个学院各一份的通知里。

🔎

找不到原文

“宿舍床多大？” 答案可能在学生手册，也可能藏在某张附表里。

问学长学姐 → 得到的是经验，不是原文
⚠️

通用大模型会编

它不知道重庆大学的具体规定，却会用“一般大学都这样”来回答。

日期、金额、电话，都是幻觉重灾区
⏳

资料还会过期

2025 年的旧通知，对 2026 级很可能已经变了；可怕的是模型不知道它过期。

旧版规则 + 不提醒 = 更危险
Three Scenarios

三个最容易被问到的场景

不是“万能聊天”，而是把新生真正要办的事，变成能查、能核对、能执行的回答。

01

军训 / 报到

集合时间、连队、服装要求、军训准备，一次讲清，并标出原文位置。

“军训要准备什么？” → 按通知列清单
02

宿舍 / 选课

宿舍床尺寸、校园卡、选课通知——多格式资料也能被读成能回答的句子。

“虎溪校区宿舍床多大？” → 直接给尺寸表
03

不知道就认怂

资料里没有的，它不会硬编。明确说“没有”，并建议问辅导员或查官方通知。

“宿舍能不能养猫？” → 资料里没有，不编
Why Trust It

不是“更会聊”，而是“更能核对”

一个校园问答工具，最重要的不是文采，而是你能否沿着答案回到原文。

📎

每条答案带出处

文件名 + 第几块，点开就能看原文摘录。

🛑

不知道就拒答

资料里没有，就明确说没有，不用常识补全。

🕒

过期会提醒

资料带“仅适用于某年级”的声明，回答会主动提示。

🔒

隐私会忽略

不透露、不推测姓名、学号、手机号、群聊内容。

How It Works

一条朴素的 RAG 流水线

不训练模型、不需要显卡；先把相关资料找出来，再让模型照着资料回答。

STEP 01中文分词jieba + 高校专有词表：军训、绩点、床位、奖学金…
STEP 02检索倒排索引 + TF-IDF + 同义词/来源加权，取 top-5。
STEP 03组装 Prompt5 块资料 + 问题 + “只能依据资料”的规则。
STEP 04带出处回答DeepSeek 生成；前端展示来源卡片和原文。
